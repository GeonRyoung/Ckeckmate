# 현대 경고·표시와 대처 원문 검토 — 2026-10-28

확보한 현대 35개 설명서를 기준으로 검토한다. 기본 PDF 26개는 계기판 경고·표시·메시지와 대처에 필요한 비상/정비 참조를 읽었다. 특장 PDF 2개는 특장 고장·경보표와 연결 비상 절차를 별도 검토했다. 웹 7개는 계기판과 주요 정비 절을 읽었지만 ADAS/EPB 후속 참조 확인을 추가 진행 중이다. 전체 완료 상태는 `hyundai-source-reading-closure.json`을 기준으로 하며, 웹 7개의 참조가 닫히기 전에는 전체 완료로 표시하지 않는다.

원문 독해는 AI 검토이며 정비 전문가의 승인이나 차량 실증 검증이 아니다. 모든 규칙은 `runtimeApproved=false`, `expertApproved=false`이고, 문장 요약을 완전한 실행형 분기 코드로 변환하는 작업은 끝나지 않았다. 원문이 모호한 항목은 읽음 여부와 별개로 앱 안내를 보류한다.

## 검토 방법과 범위

- 실제 계기판 절과 목차로 경고 목록을 만들고, 비상·정비 절에서 정지, 시동 OFF, 재시동, 보충, 견인, 금지 조건을 대조했다. 95개 SDK 경고를 모든 차량에 일괄 적용하지 않았다.
- 중복은 완전히 읽은 기준 문맥과 변경된 원문 전체를 대조하거나, 숫자·부정어·조건을 보존한 동일 문장 단위로 묶어 읽었다. 원래 순서와 문서별 연결은 `.local/manual-review`에 남겼다. 검색 결과나 같은 키워드만으로 검토 완료 처리하지 않았다.
- 기본 PDF의 연결 검토는 과열 15, 오일 15, 냉각수 26, 브레이크액 26, TPMS 25, 주차브레이크/ABS 및 ESC 52개 묶음, TMK/직접 요구된 포터 잭·타이어 탈거 26, 저전압 점프 26, 별도 EV/HEV 경고 표 9, EV 사고·화재 11개 묶음이다. HREV는 전용 TPMS 경고 절을 찾지 못했으며 장비가 없다고 단정하지 않았다.
- ADAS는 고장·가림·센서 복구에 필요한 참조를 검토했다. 일반 도로 인식 성능의 모든 예시, 모든 부품 교환·정기 관리, 일반 화면 조작을 무제한 재귀 검토한 것은 아니다.
- 위험한 표 배치와 그림은 PDF 원본을 확인했다. 포터 과열의 3열 순서, 포터 TMK/잭 그림, ST1/스타리아 EV 전원 연결, 아이오닉 5 N 과열 메시지 제목/조치 열 등을 포함한다.

## 읽었지만 자동 사용을 보류하는 원문

- ST1, 아이오닉 5 N, 코나 EV의 충전 경고에 엔진/구동벨트 문구가 실제 인쇄되어 있다. OCR 착오가 아닌 원문 혼입 의심으로 기록했으며 제조사 확인 전 EV 운전자에게 벨트 조치를 내보내지 않는다.
- 스타리아 HEV의 비플러그인 시스템에 외부 충전을 연상시키는 문구, 일부 ESC OFF 지속 점등 정비 문구의 운전자 OFF 선택 조건 생략, AX의 P/N 제목과 P 본문 차이를 유지한다.
- 포터 TMK는 최초 배터리 클램프 연결과 후속 소켓 연결이 공존한다. HREV 타이어 교환 절의 엔진/수동 1단 문구도 실제 EV에 추정 전이하지 않는다.
- 일부 냉각수 혼합비율 경계, TMK 영하30도 경계와 같이 본문과 표/다른 문단의 포함 관계가 명확하지 않은 곳은 자동 수치 판정을 보류한다.

## 산출물

`data/manual-review/2026-10-28/hyundai-source-reading-closure.json`에 35문서의 출처·해시·경고 절·검토 파일·참조 상태가 있다. 기본 PDF 및 포터 ADAS 요약은 985개 기록이며, 서로 다른 단위의 기록이므로 고유 기능 수나 경고 종류 수로 해석하면 안 된다. 표 고유행 426개는 대처 382개, 일반 탐색 43개, 이어지는 행 1개로 분류했다. 웹·특장·공통 ADAS는 audit 담당의 별도 파일로 연결한다.
