# 적용성·보충설명서·교차 감사 기록

2026-10-28. AI 원문 검토이며 자동차 전문가 승인 또는 앱 실행 승인이 아니다. 모든 산출물의 `runtimeApproved`는 false다. 후보 추출과 원문 직접 검토는 별도 상태로 유지한다.

## 검토 단위와 산출물

- 현대 웹 7문서: `hyundai-web-rules-audit.json` 311개 규칙, `hyundai-web-coverage.json` 92절(대처 직접 검토 71절, 대처 없는 문맥 확인 21절). 연결 ADAS의 모든 성능 한계를 재귀적으로 검토했다는 뜻은 아니다. 메시지 절 전체를 읽었어도 실행 가능한 조건식의 완전한 분해는 별도 작업이다.
- 카니발 하이리무진 2025: 53쪽 OCR, 핵심 14쪽 이미지 대조, `audit-supplement-rules.json` 9개 특장 규칙. 정확한 2025 KA4/KA4KH 기본 웹 설명서를 추가 확보했다. 확보와 해당 기본차의 전체 의미 검토는 구분한다.
- 현대 US4SV 2026/HRSV 2025: `audit-hyundai-special-rules.json` 27개 특장 고장·경보 규칙. 냉동기 두 고장표와 캠퍼 경고/알림표 등 6쪽을 이미지 대조했다. 일반 조작·정기 정비 전체 승인으로 확장하지 않는다.
- GT 및 PV5 장비: `audit-variant-rules.json` 9개 규칙. ECS/e-LSD, 오픈베드, 프라임 시트, WAV 램프의 관련 고장·금지 조건을 직접 확인했다. 휠체어 고정 장치 전체 절차 검증은 포함하지 않는다.
- 판매 사양 31개: `audit-variant-applicability.json`에 명시 내용 발견 10, 기본 계열 내용만 확인 4, 연식 대조 필요 4, 전용 장비 자료 미식별 7, 정확 사양 적용성 미확정 5, 하이리무진 정확 2025 기본+보충 확보 1로 구분했다. 미식별은 제조사가 공개하지 않았다는 확정이 아니다.
- `audit-sdk-coverage.json`은 SDK 95타입을 빠짐없이 열거하지만 의미 매핑은 미승인이다. 95타입을 차량별 95경고로 세지 않는다.

## RAG에 함께 보존해야 하는 조건

같은 경고명이라도 차량·연식·동력계·장비 형식이 달라 조치를 공유할 수 없는 사례를 확인했다.

1. GN7/GN7HEV/NH2의 TPMS 본문은 TMK 절차를 포함한다. CN8/CN8KH/NX5/NX5KP는 타이어 밀봉제 금지 조건을 포함하므로 TMK 절차를 옮기지 않는다. TMK는 최저 압력, 컴프레서 시간, 손상 위치, 제한 속도/거리까지 붙여야 한다. 정확한 URL·해시는 웹 규칙의 TPMS source에 보존했다.
2. NH2 연료전지 냉각수는 지정 정비 인력이 취급한다. 일반 내연기관 냉각수 보충 절차나 혼합 규격을 전용하지 않는다. 수소 누출 적색 경고와 센서 이상 주황 경고도 분리한다.
3. 엔진 오일 압력 경고의 정차·시동 종료와 일반 정기 점검의 예열 절차는 다른 문맥이다. 응급 안내에 정기 점검 예열을 앞세우지 않는다.
4. 과열 조치는 증기/누수, 팬 작동, 냉각 여부에 따라 시동 유지·종료 조건이 다르다. 뜨거운 캡 개방 금지까지 같은 검색 단위에 둔다.
5. TPMS 약 1분 점멸 후 계속 켜짐은 저압 단순 점등과 다르다. 12V 충전 경고와 고전압 배터리 잔량 경고 역시 분리한다.
6. 특장 냉동기 센서 오류는 A형에서 설정 온도에 따른 비상 냉난방, B형에서 연속 냉각으로 다르다. ‘계속 작동함’을 정상으로 해석하지 않는다. 캠퍼 루프, 어린이차 스텝, 휠체어 리프트의 고장은 기본차 계기판 고장으로 합치지 않는다.

## 원문 및 기존 분류의 정정

`audit-errata.json`에 기존 62개 수집 문서 수는 유지하되 US4SV/HRSV가 기본 취급설명서가 아닌 특장 보충 자료임을 명시했다. 카니발 하이리무진도 기본차 자료를 대체하지 않는다. 현대 판매명 인코딩은 실제 UTF-8 원문에서 U+FFFD가 0개였으므로 터미널의 깨진 표시를 데이터 손상으로 잘못 확정하지 않았다.

`audit-source-anomalies.json`에는 ST1 A01 2026 PDF126(4-8), IONIQ5 N NE1N 2026 PDF179(인쇄174), KONA EV SX2EV 2025 PDF172(인쇄167)의 충전 경고에 벨트/엔진 과열 문구가 실제 인쇄된 사실을 기록했다. 세 페이지를 이미지로 직접 대조했으며 OCR 오류가 아니다. 공식 확인 전 전기차에 벨트 점검 안내를 자동 생성하지 않는다.

## 남은 적용성 경계

특장 장비 제작사 별도 설명서, HRSV 2025와 기본 포터 2026의 연식 대응, ST1 현재 판매 연식과 카탈로그 연식의 차이, 정확한 택시/리무진/상용 장비 사양 대응은 확인 범위 밖의 사실을 추정하지 않는다. 확인한 카탈로그에 해당 연식 자료가 없다는 사실과 전 세계에서 자료가 공개되지 않았다는 주장은 다르다.

현대 기본 PDF의 ADAS 고장·가림·복구 및 연결 센서 관리 문맥은 `audit-hyundai-adas-review.json`에 24문서의 직접 검토 결과를 기록했다. 고장·가림 고유 문장 973개, 추가 문맥 822개, 센서 관리 293개를 직접 읽었다. HR/HREV 두 문서는 현대 담당자의 `hyundai-legacy-adas-review.json` 10개 규칙으로 보완했다. HR은 LDW이며 LKA의 조향 보조를 전이하지 않는다. `audit-hyundai-adas-inventory.json`은 계속 추출 후보 목록으로 유지한다. 각 기능의 모든 일반 성능 제한 도해까지 재귀 검토했다는 뜻은 아니다.

기아 ADAS 28문서의 필수 참조 독해는 `audit-kia-adas-review.json`에 `sourceReadingComplete=true`로 기록했다. 기본 1,495절과 추가 431절은 일부 중복되어 서로 다른 URL은 1,629개이다. 공백만 정규화한 정확 동일 문장을 공유해 1,421+1,037=2,458개 고유 문장을 모두 직접 읽었다. 절에는 기능 도입·목차·센서 표도 포함되므로 대처법 1,629종이라는 뜻은 아니다. 구형 봉고 PU의 설정/작동 제목 안에 숨은 FCA·LDW 고장, 조명 장 HBA/IFS, 주차 보조 제한 절 뒤의 세척·고압 분사 금지까지 보완했다. PU/PUEV 조명 목차에는 HBA/IFS 항목이 없음을 확인한 상태이며 실제 차량 사양 부재로 확대하지 않는다.

독립 원문 표본 대조 `audit-kia-spotcheck.json`은 EV4/EV6 배터리 냉각수 지시 차이, MQ4의 오일·TPMS·DPF·ABS/EBD 조건을 확인했다. MQ4 2027 t00193 노란색 전방 안전 경고 설명의 빨간색 점멸 설명 중복은 제조사 확인 대상으로 보류했다. EV6 CV1 주차 충돌방지 제한 문장의 LiDAR 언급만으로 해당 차량의 LiDAR 장착을 확정하지 않는다. NQ5KH HBA 레버 문장의 주행빔/변환빔 표현 누락, AFS/IFS 표기 차이도 버튼·SDK 실행 규칙으로 임의 보정하지 않는다.

## 독해 완료와 적용 승인 구분

`audit-completion.json`에 담당한 6개 범위의 분모와 `sourceReadingComplete`를 기록했다. 이는 명시된 경고 대처 본문과 필수 참조를 읽었다는 상태이다. 원문 모순은 읽지 못한 항목이 아니라 읽고 발견하여 자동 실행을 보류한 항목이다. 일반 기능의 모든 인식 도해, 모든 재귀 참조, 별도 장비 제작사 매뉴얼까지 완료한 것으로 확대하지 않는다.

남은 적용성 작업은 판매 사양 31개의 정확 연식·장비 대응, 특장 컨트롤러 확인, SDK 95타입 의미 매핑, 제조사 모순 확인, 전문가·실차 검증이다. 전부 `runtimeApproved=false`이며 이 결과를 앱의 자동 조치 규칙으로 배포하지 않았다.

기아 직접 대처 절의 필수 하위 절 큐 133개는 `kia-child-reviewed.json`에 전부 기록했다(전문 독해 70, 기준 원문+전체 차이 59, 동일 본문 재사용 4). 배치 노트는 `kia-child-batch-01~07.json`이며, 로컬 원본 SHA-256 133건이 일치했다. 구형 legacy 하위 큐 57 URL은 `audit-kia-legacy-child-review.json`에 `sourceReadingComplete=true`로 기록되어 있다. 보존할 차이: NQ5/TK1은 R 위치 테일게이트·D/N 위치 엔진후드 열림에서 AUTO HOLD가 EPB로 전환되고, TAM ESC OFF는 2단계(0.15~3초 엔진제어, 3초 이상 엔진+제동제어), TK1 4H/4L은 약 80/40 km/h 제한, 실내 퓨즈 조명 목록은 RJ·SP3·TK1이 서로 다르다. NQ5KH 고전압 차단 플러그는 응급 상황 한정이므로 일반 안내로 자동 권고하지 않는다. 제목만 있는 디지털키 정비 페이지(SP3 t00316, TK1 t00289, MQ4KH/DL3KH t00086)의 손자 절은 수집하지 않았고 대처를 추측하지 않았다.

`audit-adas-validation.json`에서 기아 ADAS 기본/추가 원문의 SHA-256을 실제 로컬 원본과 전부 대조했고 일치했다. AI 검토 표시와 실행 미승인 조건, 감사 JSON의 UTF-8 파싱 및 U+FFFD 부재도 통과했다. `audit-validation.json`의 356개 기존 규칙 출처·95 SDK 분모·현대 웹 92절 점검은 별도로 유지한다. 수집 후보 파일은 검토 완료로 일괄 덮어쓰지 않았다.
