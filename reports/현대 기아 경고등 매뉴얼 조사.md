# 현대 기아 경고등 매뉴얼 확보 결과

2026-10-28 확인 · 대한민국 한국어 자료 · CHECKMATE

**기존 앱 변경사항은 `f21c5f9`로 커밋했고, 현대·기아 공식 설명서 62개 문서 단위의 자료를 확보했다.** 현대는 주 취급설명서 35개, 기아는 관련 웹 설명서 26개와 보충 설명서 1개다. 검증 대상 원문 자산은 합계 **990,230,243바이트, 약 990MB**이며 `.local/manual-corpus/2026-10-28/`에 보관했다. 차종별 대처 예시 12건은 원문을 직접 확인했다. **문서 확보 수는 차량별 답변 승인 수가 아니며, 모든 경고 조치의 의미 검수·전문가 승인·앱 적용은 아직 완료되지 않았다.** 기존 앱의 승인 근거는 아이오닉 5 2025 TPMS 요약 3개 그대로다.

## 공식 카탈로그를 열거하고 현재 판매 목록과 대조했다

이번 전수 범위는 공식 국내 카탈로그 항목과 현재 승용·SUV·MPV·소형상용 제품행이다. Genesis, 해외시장, 버스·중대형 트럭, 모든 과거 연식은 제외하고 사유를 남겼다. 카탈로그에 단종 차량도 있어 현재 판매 증거로 그대로 쓰지 않았다. ([현대 카탈로그](https://ownersmanual.hyundai.com/api/v2/hmc/models?countryCode=A99&langCode=ko_KR), [기아 카탈로그](https://ownersmanual.kia.com/api/v2/kia/models?countryCode=A99&langCode=ko_KR))

| 구분 | 현대 | 기아 |
|---|---|---|
| 설명서 카탈로그 | 69항목 | 41항목 |
| 현재 판매 목록 → 대상 범위 | 60행 → 44행, 버스·중대형 16 제외 | 42행 → 41행, 버스 1 제외 |
| 확보 문서 | 35개: 주 설명서 PDF 28개·14,792쪽 + 웹 7개 | 27개: 관련 절 웹 26개 + 보충 PDF 1개·53쪽 |
| 제품행 대응 | 44행 모두 차종군 자료 연결 | 기본 차종군 일치 19행, 공유 자료 후보 22행 |
| 주요 적용 공백 | 특장·택시·리무진 등 9행, ST1 연식 차이 | GT·택시·PV5 구성·특장·하이리무진 등 22행 |

**현대 44/44는 자료 연결률이다. 기아 `exact_confirmed` 19행도 모델 차종군 일치만 뜻한다.** 어느 쪽도 모든 연식·트림·전용 장비의 대처법 승인을 뜻하지 않는다. 현재 목록은 [현대 전체차량 API](https://www.hyundai.com/kr/ko/e/api/common/gnb/menus/M?siteType=H&imageSectionCode=01&includeModelYn=Y)와 기아 [EV](https://www.kia.com/kr/vehicles/ev)·[승용](https://www.kia.com/kr/vehicles/sedan)·[RV](https://www.kia.com/kr/vehicles/rv)·[상용](https://www.kia.com/kr/vehicles/commercial)·[PBV](https://www.kia.com/kr/vehicles/pbv) 페이지로 대조했다. 개별 문서·제품행은 [데이터셋 안내](../data/manual-research/2026-10-28/README.md)의 매니페스트와 대응표에서 확인할 수 있다.

최신은 조사일에 실제 공개된 공식 자료를 뜻한다. 아이오닉 5 2027 설명서는 최초 게시 2026-06-29·수정 2026-10-19, EV3 2027은 최초·최종 게시 2026-02-06이 확인됐다. 기존 앱용 아이오닉 5 2025도 별도로 보존했다. ([아이오닉 5 게시 정보](https://ownersmanual.hyundai.com/api/v2/hmc/model/owners-manuals?projectCode=NE1&year=2027&langCode=ko_KR&countryCode=A99), [EV3 게시 정보](https://ownersmanual.kia.com/api/v2/kia/model/owners-manuals?countryCode=A99&langCode=ko_KR&projectCode=SV1&year=2027))

## 파일 확보와 완전한 매뉴얼 적용을 구분했다

현대는 PDF 전체 28개, 웹 7개의 공식 검색본문·목차 3,696항목과 관련 HTML 91개를 확보했다. PDF에는 18주제별 위치 목록 504개, 웹에는 관련 항목 후보 580개를 만들었다. 기아는 관련 HTML 토픽 2,637개·최상위 목차 26개·PDF 1개를 확보했다. **위치 후보는 키워드 색인이며 검토된 경고 규칙 수가 아니다.** 현대 문서 35/35, 기아 자산 2,664개의 해시·크기·형식 검사에 실패가 없었으며, 현대는 PDF 페이지 수와 웹 목차·본문 대응도 확인했다. ([현대 검증](../data/manual-research/2026-10-28/hyundai-validation.json), [기아 검증](../data/manual-research/2026-10-28/kia_validation.json))

기아 웹 26개는 경고·비상조치·점검 관련 절의 **부분 수집**이다. 양 브랜드 모두 모든 이미지·CSS를 가진 오프라인 사이트를 만든 것은 아니다. 카니발 하이리무진 2025 PDF는 전용 부품의 보충 설명서이며 텍스트층이 없어 OCR이 필요하다. 정확한 2025 기본 카니발 설명서 연결도 남아 있다. ST1은 판매 API 이미지에 2027 표기가 있으나 공개 최신 설명서는 2026이므로 자동 연식 적용을 보류한다. ([기아 문서 목록](../data/manual-research/2026-10-28/kia_manifest.json), [ST1 공식 설명서 정보](https://ownersmanual.hyundai.com/api/v2/hmc/model/owners-manuals?projectCode=A01&year=2026&langCode=ko_KR&countryCode=A99))

## 다음 단계는 원문을 차량별 승인 근거로 바꾸는 작업이다

SDK 2.3.2에는 경고·표시 타입 **95종**, 콘솔에는 입력 **37종**, 현재 앱 설명에는 **1종**이 있다. 타입 선언은 실차 제공 보장이 아니다. 현재 앱은 type/state만 저장하며 color·priority·warningCount는 보존하지 않고, 설명 서버에 현재 동시 경고 목록도 전달하지 않는다. 따라서 색상·동시 경고·점멸 지속시간이 필요한 예시를 현재 입력만으로 확정하면 안 된다. ([전수 신호 매핑](../data/manual-research/2026-10-28/warning_mapping.json), [수신 코드](../android/app/src/main/java/com/checkmate/pleos/vehicle/PleosWarningSource.kt))

새 [근거 스키마](../data/manual-research/2026-10-28/warning_evidence.schema.json)는 차량·연식·시장·파워트레인, 원문 해시·판본·위치, 관측 조건·행동·금지 추론, 검토·검색 승인을 나눴다. Draft 2020-12 구조 검사는 통과했으며 의미 정확성 검사는 별도다. 다음에는 기존 아이오닉 5 2025 TPMS부터 본문·표·조건을 검토하고, 차종·연식·동시 경고가 섞이지 않는 평가를 거쳐 근거를 확대하는 것이 적합하다. **임베딩·벡터 검색·신규 답변 활성화는 이번 작업에 포함하지 않았다.**

원본은 Git 제외 폴더에 두고 목록·검증 결과·조사 스크립트를 분리했다. [데이터셋 안내](../data/manual-research/2026-10-28/README.md)에 모든 산출물과 재현 명령이 있다. 현재 수집기는 2026-10-28 캐시 재현용이므로 다음 최신성 갱신에는 새 날짜·카탈로그·게시일 재조회가 필요하다. 공개 앱의 원문 재배포·인용 범위도 별도 확인 대상이다.
